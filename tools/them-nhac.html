Chưa chọn thư mục web

Trước tiên, cho trang biết thư mục web

Chọn thư mục web (thư mục có index.html, ví dụ steamapikey) hoặc thẳng thư mục music bên trong. Nhạc nằm ở music/, danh sách bài ở music/tracks.js, lời bài hát là file .lrc cùng tên với file mp3.

Cách nhanh (Chrome / Edge) · nên dùng

Trang tự chép mp3 vào music/, tự ghi tracks.js và lưu file lời. Lần sau mở lại chỉ cần 1 lần bấm.

Cách thường (mọi trình duyệt)

Chọn file music/tracks.js. Xong thì tải bản mới về, đè lên file cũ và tự chép mp3 vào thư mục music.

Chưa có danh sách. Hãy chọn thư mục web hoặc file music/tracks.js ở tab ① Thêm bài mới.

Chưa chọn bài. Chọn một bài ở trên, hoặc bấm "Làm lời" ở tab Thêm bài / Danh sách.
  1. Chọn bài
  2. Lấy lời có sẵn, hoặc dán lời rồi chia dòng
  3. Phát nhạc, bấm Space đúng lúc mỗi câu bắt đầu
  4. Lưu file .lrc
